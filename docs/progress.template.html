Teaching an AI to hear isiXhosa

Whisper is a free speech-to-text model from OpenAI that understands 99 languages, but not isiXhosa. We are teaching it isiXhosa using 56 hours of recorded speech, on a computer rented from Amazon by the hour. You make the decisions; Claude Code agents write and run everything. What is happening right now

One rented GPU computer in the USA (an NVIDIA L4) is working through this list. It started at 09:31 your time and switches itself off when done, after 4 hours at most.

  1. Set up and a 2-minute safety test, to make sure nothing is broken before the long part.
  2. Copy the 46,651 isiXhosa audio clips from our storage onto the computer.

How the training works

Words you'll keep hearing

Fine-tuning
Taking a model that already knows a lot (Whisper) and continuing to train it on new data (isiXhosa), instead of starting from zero.
Language tag
The first thing Whisper writes for every clip: which language it is. isiXhosa has no tag, so we borrow Swahili's (decision D-0007).
Train / dev / test
Train speakers are who it learns from. Dev speakers are a quiz to pick the best saved copy. Test speakers are the final exam, never seen during training.
Seen vs unseen
82% of test clips use sentences that other people also read in the training data. We report a separate score on the unseen sentences, because that's the honest measure of real understanding.
Checkpoint
A saved copy of the model partway through training, so a crash doesn't lose everything and we can keep the best one.
Overfitting
When the model memorises the training speakers instead of learning the language. Shows up as the dev score getting worse while training continues.
GPU
The kind of chip that makes AI training fast. We rent one by the hour from Amazon (about $0.80/hour).

Problems we hit, and what they taught us

P-0001

No progress bar on a download

A 15-minute download said nothing until it finished. Now every long job reports progress.

Long cloud jobs must report on themselves.

P-0002

Couldn't look inside the GPU computers

Fixed: agents can now run checks on a running machine without opening it to the internet.

Decide how you'll get inside before you need to.

P-0003

No discounted GPUs available

Amazon's cheap "spot" computers were all taken, so we used a regular one.

Cheap capacity isn't guaranteed.

P-0004

Windows hid a character in file names

An invisible line-ending character made files look missing. Fixed in the script.

Windows and Linux tools disagree about invisible characters.

P-0005

A missing software library

The rehearsal caught it before the expensive run. A 2-minute safety test now runs first.

The cheapest place to find a bug is the smallest run.
